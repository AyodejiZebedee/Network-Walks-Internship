
# Building a Personal Cybersecurity Lab Using VMware, Kali Linux and Docker

## Project Overview

This project documents the design, installation and configuration of a personal cybersecurity laboratory using VMware Workstation, Kali Linux and Docker.

The objective is to establish an isolated virtual environment where cybersecurity concepts can be studied and practical exercises performed safely without affecting external systems.

## Objectives

Set up a virtual cybersecurity laboratory.

Install and configure Kali Linux.

Configure Docker for containerized environments.

Establish virtual network connectivity.

Verify communication between laboratory components.

Document the complete laboratory setup.
